## itch.io upload

1. New project → Kind of project: **HTML**.
2. Upload `dist/round13-web.zip`, tick **This file will be played in the browser**.
3. Embed options: viewport **960×720** (4:3), enable the **Fullscreen button**, **Mobile friendly** off (needs mouse and keyboard).
4. Save as draft, open the page, run the manual checks above, then publish.

## Known limitations

- Desktop only (mouse and keyboard).
- The round number persists in the browser's local storage (`round13.round`); clearing site data restarts at Round 13.
- No automated unit tests yet (no JS runtime on the dev machine); `src/js/shift.js` is pure logic and ready for them.
